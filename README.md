# Tebbets Community Club

Static website for the Tebbets Community Club, served by GitHub Pages.

**Live site:** https://justcynthia.github.io/Longaberger/

## Editing

No build step. Edit the HTML/CSS directly and push to `main`:

```bash
git add -A
git commit -m "Update hours on the events page"
git push
```

Changes go live in about 30 seconds.
